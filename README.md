# A* Algorithm-Based Intelligent Pathfinding System

##  Description
This project implements the A* pathfinding algorithm to determine the shortest path between two points in a grid-based environment. It simulates real-world navigation scenarios such as smart city routing with obstacles and weighted paths.

##  Features
- Interactive grid system
- Start and end node selection
- Obstacle handling
- Weighted nodes (traffic simulation)
- Real-time path visualization
- Diagonal movement support

##  Technologies Used
- Python
- Pygame

##  Controls
- Left Click → Set Start, End, Walls
- Right Click → Remove
- Middle Click → Weighted Node
- SPACE → Run Algorithm
- C → Reset Grid

##  Algorithm Used
A* (A-Star) Algorithm:
f(n) = g(n) + h(n)

##  Output
Displays shortest path using color visualization.

##  Applications
- Smart city navigation
- Robotics path planning
- Game development
